# OCR runtime

`models` is generated by `scripts/setup_backend.ps1`. It contains the PP-OCRv6 Medium detector, PP-OCRv6 Small page recognizer, PP-OCRv6 Medium risk-cell recognizer, and the SLANetPlus table-structure model used by the local backend.

Generated model files and packaged executables are not source files and should be distributed as release artifacts rather than committed to the repository.
